# Искра — Идеи и Вдохновение

Красивое веб-приложение для генерации идей и получения вдохновения.

## Что внутри

- **Полноэкранный герой** с меняющимися расслабляющими пейзажами
- **Галерея** из 12 вдохновляющих фотографий природы
- **Генератор идей** с 6 категориями (Письмо, Бизнес, Искусство, Жизнь, Технологии, Безумные)
- **Карточки-упражнения** для запуска креативности
- **Сохранение идей** (хранятся в браузере)
- Красивый тёмный дизайн с мягкими анимациями

## Как открыть

Просто открой `index.html` в любом современном браузере.

Или запусти локальный сервер:

```bash
npx serve .
```
